# Contributing to Barrels Expanded

Thanks for wanting to contribute.

You can contribute by:

- Opening bug reports.
- Suggesting improvements.
- Sending pull requests.
- Helping test multiplayer behavior.
- Improving translations or documentation.

By submitting a pull request or contribution, you confirm that:

- The contribution is your own work, or you have permission to submit it.
- The contribution does not include copied code or assets from Project Zomboid, The Indie Stone, other mods, or third parties unless explicitly permitted.
- The contribution may be incorporated into Barrels Expanded.
- You agree that your contribution will be licensed under the same license as the project (see [LICENSE](LICENSE)).

Please do not submit:

- Obfuscated code.
- Malicious code.
- Decompiled game code.
- Game assets copied from Project Zomboid.
- Code or assets copied from other mods without permission.
- Large rewrites without opening an issue first.

Pull requests may be rejected, modified, squashed, delayed, or closed at the author's discretion.
